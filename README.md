# go-screen-burn-in-fixer

在全螢幕即時播放「螢幕修復畫面」的小工具：快速閃爍的雜訊、彩色條紋、純色輪播與移動色條，讓面板上每個紅、綠、藍子像素在全亮與全暗之間反覆切換。播放結束後可以自動關閉程式、關機、睡眠，或切換成節奏緩慢的螢幕保護畫面。

另外內建**檢查畫面**：灰階、單色、近黑、漸層、全黑全白與殘影測試，用來找出烙印、暫時性殘影、壞點與不均勻。

- **單一 exe**：不需要安裝任何東西，點兩下就能執行。
- **即時產生畫面**：由顯示卡即時運算，任何解析度、更新率都清楚，不需要下載或轉檔影片。
- **自動配合螢幕**：預設使用目前螢幕的解析度，也能讀取 EDID 顯示原生解析度。
- **多螢幕**：可以選擇一個、幾個或全部螢幕同時播放或檢查。

## ⚠️ 警告

- **本程式內含快速閃爍畫面。光敏性癲癇患者或對閃光敏感的人請勿觀看。** 播放時請避免一直盯著螢幕。
- **真正的 OLED 烙印是永久性的面板老化，無法用任何畫面修復。** 本工具可能有助於減輕**暫時性殘影**（image retention）或喚醒**卡住的像素**，但不保證有效。
- 長時間以最高亮度播放會增加面板負擔，請自行斟酌播放時間。

## 畫面

每種畫面的 3 秒預覽影片放在 [`previews/`](previews/README.md)。

### Burn-In 圖樣

| 名稱 | 畫面 |
|---|---|
| `gray-noise` | 每格重新產生的灰階雜訊（1 像素） |
| `rgb-noise` | 紅、綠、藍子像素各自隨機全開或全關的雜訊 |
| `vstripes` / `vstripes-fine` | 隨機顏色的直條紋（寬 4 像素 / 1 像素） |
| `hstripes` / `hstripes-fine` | 隨機顏色的橫條紋（寬 4 像素 / 1 像素） |
| `cross` / `cross-fine` | 直條紋與橫條紋交錯成的十字格紋（寬 4 像素 / 1 像素） |
| `solid-cycle` | 全螢幕紅 → 綠 → 藍 → 白 → 黑輪播 |
| `moving-bar` | 黑底白色色條，水平、垂直輪流掃過螢幕 |

### 檢查畫面

檢查畫面上**沒有任何文字**；需要的資訊顯示在可隱藏的資訊列。

| 名稱 | 畫面 | 檢查什麼 |
|---|---|---|
| `gray-field` | 灰階 5、10、18、25、35、50、75% | 烙印的影子（18–35% 最明顯） |
| `gray-steps` | 灰階分階，階數 2–256 可自訂 | 螢幕能分辨的灰階數、暗部細節 |
| `color-field` | 紅、綠、藍各 25、50、100% | 子像素老化不平均、判斷哪個子像素壞了 |
| `retention-test` | 黑白格紋 10 秒後切換成灰色 | 暫時性殘影多久消失 |
| `black` | 全黑 | 亮點、卡住的像素 |
| `white` | 全白 | 暗點、死像素、灰塵 |
| `near-black` | 近黑 1、2、3、5% | 暗部不均勻（雲斑、mura）、角落偏亮 |
| `gradient` | 灰階與紅綠藍漸層（水平／垂直） | 不規則的斷層或色偏 |

百分比是 8 位元訊號值的比例（例如 25% = 64/255），不是亮度。

灰階分階最多 256 階：本程式送出的是 8 位元訊號，每個顏色只有 256 階。10 位元面板（1024 階）或 HDR 的暗部、峰值亮度需要 10 位元或 HDR10 訊號才能測試，目前不支援；在這些螢幕上，256 階仍可以看出斷層與暗部被壓黑的問題。

#### 怎麼分辨暫時性殘影和永久烙印

1. 用 `gray-field`（25%）找到影子，點一下標記位置。
2. 播放 Burn-In 修復 30–60 分鐘，或讓螢幕待機（不要拔電源）讓面板執行像素補償。
3. 再檢查一次：影子消失了是**暫時性殘影**；經過多次補償仍然存在，很可能是**永久烙印**。

注意：
- 本程式輸出一般的 SDR 畫面（8 位元），無法送出 HDR 高亮度訊號。Windows 開啟 HDR 時畫面亮度受「SDR 內容亮度」影響，每次檢查請使用相同設定。
- 曲面螢幕（例如 1000R）的兩側是斜著看的，本來就可能看起來偏暗或偏色，這不是烙印；請坐在螢幕正中央，有疑慮的地方轉頭正對著再看一次。

### 螢幕保護畫面

亮度低、不會閃爍，畫面持續移動，不會長時間停在同一個位置。

| 名稱 | 畫面 |
|---|---|
| `drift-clock` | 在整個螢幕漂移、慢慢變色的時鐘 |
| `aurora` | 流動的深色漸層色帶 |

## 使用方式

### 點兩下執行

1. 執行 `go-screen-burn-in-fixer.exe`。
2. 閱讀警告畫面，按任意鍵繼續。
3. 在設定選單選擇模式：**Burn-In 修復**、**檢查畫面**或**只播螢幕保護**，再勾選要使用的螢幕與該模式的項目。滑鼠指到的項目會在右側即時預覽。
4. 按「開始播放」／「開始檢查」或 Enter，在選定的螢幕全螢幕播放。設定會存在 exe 旁邊的 `go-screen-burn-in-fixer.json`，下次開啟時沿用。

設定選單可以全程用鍵盤操作：↑↓ 選擇、←→ 調整、空白鍵勾選、Enter 開始、Esc 結束。

### 多螢幕

有多個螢幕時，設定選單的「螢幕」每個螢幕一個勾選框，勾選幾個就同時在幾個螢幕上全螢幕播放（←→ 選擇螢幕、空白鍵勾選）。

- 所有螢幕一起計時、一起結束；在任何一個螢幕按 Esc 會全部停止。
- 暫停、切換圖樣、檢查畫面換階，所有螢幕同步。
- 時間到後關機或睡眠只會倒數一次（倒數時其他螢幕顯示全黑，在任何螢幕按鍵都能取消）；螢幕保護則每個螢幕都播。
- 檢查畫面的標記每個螢幕分開記錄。

技術上，第一個勾選的螢幕由主程式播放，其他每個螢幕各開一個同樣的程式（工作管理員會看到多個 `go-screen-burn-in-fixer.exe`），主程式結束時會一起結束。

### 洗牌播放

「圖樣」旁選「洗牌」時，每個圖樣的時間會切成一小段一小段，和其他圖樣交錯播放，例如 gray-noise 播 40 秒、換 vstripes 25 秒、再換 moving-bar……之後又回到 gray-noise。

- 清單裡每個圖樣的秒數變成**一輪的總時間**，洗牌後總時間不變。
- 「每段」可以選 15–60 秒隨機（預設）或固定 10、20、30、60 秒。

### 播放時間

「播放時間」可以用 ◀▶ 選常用值（5 分鐘到 24 小時），選到這一列時也可以直接輸入，最長 72 小時：

| 輸入 | 意思 |
|---|---|
| `90` | 90 分鐘 |
| `3h` | 3 小時 |
| `2:30`、`2h30m` | 2 小時 30 分 |

按 Enter 確定，Esc 取消輸入。
- 同一個圖樣不會連續出現；播放時間超過一輪時，每一輪重新洗牌。某個圖樣佔一輪一半以上的時間時，它每一段會比較長，才能和其他圖樣交錯。
- 資訊列顯示這個圖樣在這一輪已播放的時間，例如「gray-noise　本輪 3:20 / 10:00」。

### 播放 Burn-In 時的按鍵

| 按鍵 | 功能 |
|---|---|
| Esc | 回到設定選單（以命令列參數執行時直接結束） |
| 空白鍵 | 暫停 / 繼續 |
| ← / → | 上一個 / 下一個圖樣 |
| H | 顯示 / 隱藏資訊列（目前圖樣、剩餘時間、FPS） |
| 按住 S | 按著時顯示資訊列 |

### 檢查畫面

- 勾選要進行的檢查項目，依序進行。有多「階」的項目（例如灰階 7 階），秒數指每一階的時間。
- 每個項目可以設定秒數（5–120 秒）或**手動**（按 Enter／空白鍵才進行下一階）。上方「全部設為」可以一次把全部項目設成自動 10 秒或手動。
- 灰階分階的階數可以用 ◀▶ 切換常用值（8、16、32、64、128、256），選到這一列時也可以直接輸入數字（2–256）。
- 全部完成或按 Esc 取消後，回到檢查選單。

| 按鍵 | 功能 |
|---|---|
| Enter／空白鍵 | 下一階（手動時必須按；自動時可以提早跳過） |
| ← | 上一階 |
| Esc | 取消，回到檢查選單 |
| 滑鼠 | 移動時顯示十字游標與像素座標；點一下標記可疑位置，再點一下取消 |
| C | 清除全部標記 |
| M | 隱藏 / 顯示標記 |
| H | 顯示 / 隱藏資訊列 |
| 按住 S | 按著時顯示資訊列 |

標記會存檔，下次開啟時保留，方便在 Burn-In 修復之後於同一位置再檢查一次；可在檢查選單清除。

### 資訊列

設定選單的「資訊列」決定播放與檢查時左上角資訊列的顯示方式（Burn-In 與檢查共用）：

| 設定 | 行為 |
|---|---|
| 不顯示 | 平常不顯示；按住 S 或按 H 才出現 |
| 3／5／10 秒 | 切換圖樣或階、移動滑鼠時顯示幾秒後自動隱藏（預設 5 秒） |
| 一直顯示 | 一直顯示 |

### 定時與後續動作

| 動作 | 說明 |
|---|---|
| `quit` | 關閉程式 |
| `shutdown` | 倒數 60 秒後關機（倒數中按任意鍵取消） |
| `sleep` | 倒數 60 秒後進入睡眠（倒數中按任意鍵取消） |
| `screensaver` | 停止閃爍，切換成螢幕保護畫面，按鍵或移動滑鼠後結束 |

### 命令列參數

帶播放相關參數（`-program`、`-timer`、`-after`、`-screensaver`、`-monitor`、`-check`、`-shuffle`）執行時，會跳過警告畫面與設定選單直接開始播放，方便排程使用；這些參數只用於這次執行，不會改到設定檔：

```
go-screen-burn-in-fixer.exe -program "gray-noise:600,vstripes:300,solid-cycle:120" -timer 30m -after screensaver
go-screen-burn-in-fixer.exe -monitor all -shuffle -timer 1h -after sleep
```

| 參數 | 說明 |
|---|---|
| `-program` | 節目表，格式為 `圖樣:秒數`，以逗號分隔（預設：全部圖樣輪流，共 50 分鐘） |
| `-timer` | 定時長度，例如 `30m`、`1h` |
| `-after` | 時間到之後的動作：`quit`、`shutdown`、`sleep`、`screensaver` |
| `-screensaver` | 螢幕保護畫面名稱 |
| `-monitor` | 使用的螢幕（從 1 開始）：`2`、`1,2` 或 `all`（全部） |
| `-shuffle` | 洗牌播放 |
| `-shuffle-slice` | 洗牌時每段的秒數；`0` 代表隨機 15–60 秒 |
| `-list` | 列出所有圖樣與螢幕保護畫面 |
| `-list-monitors` | 列出螢幕（目前解析度與 EDID 原生解析度） |
| `-windowed` | 以視窗模式執行 |
| `-dry-run` | 測試用：時間到時不真的關機或睡眠 |
| `-countdown` | 關機 / 睡眠前的倒數時間（預設 `60s`） |
| `-check` | 直接開始檢查，例如 `"gray-field:5,gray-steps:manual,white"`（每階秒數或 `manual`；省略時用選單設定）。完成或按 Esc 後結束程式 |
| `-gray-levels` | 灰階分階的階數（2–256） |

## 建置

需要 Go 1.27 以上：

```
go build -trimpath -ldflags "-s -w -H windowsgui" -o dist/go-screen-burn-in-fixer.exe .
```

exe 的圖示、版本資訊與 manifest 來自 `winres/`，由 [go-winres](https://github.com/tc-hib/go-winres) 產生 `rsrc_windows_*.syso`（已納入版本控制，`go build` 會自動使用）。修改圖示或版本號後重新產生：

```
go install github.com/tc-hib/go-winres@latest
go run ./tools/icon                      # 重新繪製 winres/icon.png、icon16.png（只改版本號時不需要）
go-winres make --arch amd64,arm64
```

### 「Windows 已保護您的電腦」

從網路下載、沒有程式碼簽章的 exe，第一次執行時 SmartScreen 會顯示這個畫面，這不代表程式有問題。點「其他資訊」→「仍要執行」即可；或在檔案上按右鍵 →「內容」→ 勾選「解除封鎖」。

產生預覽影片（需要 ffmpeg）：

```
go run ./cmd/preview
```

## 新增圖樣

每個圖樣是 `patterns/` 下的一組 `.go` 與 `.kage`（Ebitengine 的 shader）檔案，在 `init()` 裡註冊，不需要修改其他程式碼。詳細步驟見 [CLAUDE.md](CLAUDE.md) 第 3.3 節。螢幕保護畫面（`screensaver/`）與檢查畫面（`checks/`）的做法相同。
