「画面修復パターン」をリアルタイムで全画面表示する小さなツールです。高速に点滅するノイズ、カラーのストライプ、単色の切り替え、移動するバーによって、パネル上の赤・緑・青のサブピクセルひとつひとつを全点灯と全消灯の間で繰り返し切り替えます。再生が終わったら、プログラムを終了する、シャットダウンする、スリープする、またはゆっくり動く暗いスクリーンセーバーに切り替えることができます。

さらに**チェック画面**も内蔵しています。グレー、単色、黒に近い色、グラデーション、全黒・全白、残像テストで、焼き付き、一時的な残像、ドット抜け、ムラを見つけられます。

- **実行ファイルひとつ**：インストール不要、ダブルクリックで起動。Windows、macOS（Apple Silicon / Intel）、Ubuntu などの Linux x64 に対応。
- **リアルタイム生成**：GPU で計算するので、どの解像度・リフレッシュレートでも鮮明。動画のダウンロードや変換は不要です。
- **モニターに自動で合わせる**：標準では現在の解像度を使い、EDID を読み取ってネイティブ解像度も表示できます。
- **マルチモニター**：1 台、複数台、または全モニターで同時に再生・チェックできます。

## ⚠️ 警告

- **このプログラムには高速に点滅する映像が含まれます。光過敏性てんかんの方、点滅する光に敏感な方は見ないでください。** 再生中は画面を見つめ続けないでください。
- **本当の OLED の焼き付きはパネルの永久的な劣化であり、どんな映像でも直せません。** このツールは**一時的な残像**（image retention）の軽減や、**動かなくなったピクセル**（stuck pixel）の回復に役立つ可能性がありますが、効果は保証しません。
- 最大輝度で長時間再生するとパネルに負担がかかります。再生時間はご自身で判断してください。
- **ご利用は自己責任でお願いします。** このツールは「現状のまま」提供され、効果は保証しません。作者は、使用後に起きたいかなる事態にも責任を負いません。これには、モニターやパネルの損傷、残像や焼き付きの悪化、明るさや色の変化、自動シャットダウンによるデータの消失、体調不良などが含まれます。使用前にモニターメーカーの説明書をお読みください（多くの OLED モニターにはピクセルリフレッシュ機能が内蔵されており、メーカーは通常そちらを先に使うことを勧めています）。

## 画面

各画面の 3 秒のプレビュー動画は [`previews/`](previews/README.md) にあります。

### Burn-In パターン

| 名前 | 画面 |
|---|---|
| `gray-noise` | フレームごとに作り直すグレーのノイズ（1 ピクセル） |
| `rgb-noise` | 赤・緑・青のサブピクセルがそれぞれランダムに全点灯・全消灯するノイズ |
| `vstripes` / `vstripes-fine` | ランダムな色の縦ストライプ（幅 4 ピクセル / 1 ピクセル） |
| `hstripes` / `hstripes-fine` | ランダムな色の横ストライプ（幅 4 ピクセル / 1 ピクセル） |
| `cross` / `cross-fine` | 縦と横のストライプを組み合わせた格子（幅 4 ピクセル / 1 ピクセル） |
| `solid-cycle` | 全画面で 赤 → 緑 → 青 → 白 → 黒 を繰り返す |
| `moving-bar` | 黒地に白いバーが、横方向と縦方向に交互に流れる |

### チェック画面

チェック画面には**文字を一切表示しません**。必要な情報は、隠すこともできる情報バーに表示します。

| 名前 | 画面 | 何を確認するか |
|---|---|---|
| `gray-field` | 全画面グレー、最も暗い値から最も明るい値まで段階的に（標準は 13–191 の 7 段階、約 5–75%） | 焼き付きの影（18–35% が最も見やすい） |
| `gray-steps` | グレーの階調、2–256 段階 | モニターが区別できる階調数、暗部のディテール |
| `color-field` | 赤・緑・青 それぞれ 25、50、100% | サブピクセルの劣化のばらつき、どのサブピクセルが故障しているか |
| `retention-test` | 白黒の市松模様を 10 秒表示した後、グレーに切り替え | 一時的な残像が消えるまでの時間 |
| `black` | 全黒 | 輝点、動かなくなったピクセル |
| `white` | 全白 | 黒点、ドット抜け、ほこり |
| `near-black` | 黒に近い 1、2、3、5% | 暗部のムラ（雲状のムラ、mura）、四隅の明るさ |
| `gradient` | グレーと RGB のグラデーション（横 / 縦） | 不規則な段差や色ずれ |

パーセントは 8 ビット信号値の割合（例：25% = 64/255、50% ≈ 128）で、実際に発光する明るさではありません。モニターにはガンマ（約 2.2）があるため、信号 128 の実際の発光量は全白の約 22% です。ただし人の目の明るさの感じ方も非線形なので、信号値の割合のほうが「見た目」の明暗に近くなります。

階調は最大 256 段階です。このプログラムは 8 ビット信号を出力するため、各色 256 段階しかありません。10 ビットパネル（1024 段階）や HDR の暗部・ピーク輝度のテストには 10 ビットまたは HDR10 の信号が必要で、現在は対応していません。それらのモニターでも、256 段階で段差や黒つぶれは確認できます。

#### 一時的な残像と永久的な焼き付きの見分け方

1. `gray-field`（約 25%、グレー 64 付近）で影を見つけ、クリックして位置をマークします。
2. Burn-In パターンを 30–60 分再生するか、モニターを待機状態にして（電源は抜かずに）パネルのピクセルリフレッシュを実行させます。
3. もう一度チェックします。影が消えていれば**一時的な残像**、何度リフレッシュしても残る場合は**永久的な焼き付き**の可能性が高いです。

注意：
- このプログラムは通常の SDR 映像（8 ビット）を出力し、HDR の高輝度信号は出せません。Windows で HDR をオンにしている場合、明るさは「SDR コンテンツの明るさ」の設定に左右されるので、毎回同じ設定でチェックしてください。
- 曲面モニター（例：1000R）の両端は斜めから見ることになるため、もともと暗く見えたり色がずれて見えたりすることがあります。これは焼き付きではありません。画面の正面中央に座り、気になる場所は顔をそちらに向けて正面から見直してください。

## 使い方

### ダウンロード

[Releases](https://github.com/The78estHerry/go-screen-burn-in-fixer/releases) から、お使いのシステム用のファイルをダウンロードしてください。

| システム | ファイル |
|---|---|
| Windows x64 | `go-screen-burn-in-fixer-<バージョン>-windows-amd64.exe` |
| macOS（M1 以降の Apple Silicon） | `go-screen-burn-in-fixer-<バージョン>-macos-apple-silicon.zip` |
| macOS（Intel） | `go-screen-burn-in-fixer-<バージョン>-macos-intel.zip` |
| Ubuntu などの Linux x64 | `go-screen-burn-in-fixer-<バージョン>-linux-amd64.tar.gz` |

**Windows**：初回実行時に「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」をクリックしてください（コード署名がないためです）。

**macOS**（macOS 12 以降）：解凍して `go-screen-burn-in-fixer.app` を「アプリケーション」にドラッグします。Apple の開発者署名がないため、初回起動はブロックされます（「開けません」または「壊れています」）。次のどちらかで対処してください。
- 「システム設定」→「プライバシーとセキュリティ」の下のほうにある「このまま開く」をクリック。
- または「ターミナル」で実行：`xattr -cr /Applications/go-screen-burn-in-fixer.app`

設定ファイルは `~/Library/Application Support/go-screen-burn-in-fixer/` に保存されます。シャットダウン機能を初めて使うとき、macOS が「システムイベント」の制御を許可するか尋ねるので、許可してください。

**Linux**：

```
tar xzf go-screen-burn-in-fixer-<バージョン>-linux-amd64.tar.gz
cd go-screen-burn-in-fixer-<バージョン>-linux-amd64
./go-screen-burn-in-fixer
```

グラフィカルデスクトップ（X11、または Wayland 上の XWayland）と OpenGL が必要で、Ubuntu デスクトップ版には標準で入っています。再生中は `systemd-inhibit` と `xdg-screensaver` で画面が消えないようにし、シャットダウンとスリープには `systemctl poweroff`、`systemctl suspend` を使います。

**macOS と Linux の制限**：モニター名と EDID のネイティブ解像度は、現在 Windows でのみ取得できます。他のシステムではメニューにモニター番号と解像度だけが表示され、`-list-monitors` も使えません。

**macOS と Linux は、まだ実機でテストしていません。** 報告をいただけると助かります。

### ダブルクリックで起動

1. `go-screen-burn-in-fixer.exe` を実行します。
2. 警告画面を読み、何かキーを押して続けます。
3. 設定メニューでモードを選びます：「Burn-in repair」（Burn-In 修復）、「Test screens」（チェック画面）、「Screensaver only」（スクリーンセーバーのみ）。使うモニターと、そのモードの項目にチェックを入れます。マウスを合わせた項目は右側でリアルタイムにプレビューされます。
4. 「Start」（再生開始）／「Start test」（チェック開始）または Enter で、選んだモニターに全画面で表示します。設定は exe と同じフォルダーの `go-screen-burn-in-fixer.json` に保存され、次回も使われます。

設定メニューはすべてキーボードで操作できます：↑↓ 選択、←→ 調整、スペース チェック、Enter 開始、Esc 終了。

### 画面の言語

画面は**英語**と**繁体字中国語**で、標準は英語です。最初の警告画面と設定メニューの右上にある「English | 中文」をクリックすると切り替わります（警告画面では ← → でも可能。メニューでは ↑ で一番上に移動して ←→）。画面の文字はすぐに変わり、選択は設定ファイルに保存されます。コマンドラインでは `-lang en` または `-lang zh` で指定できます。

### マルチモニター

モニターが複数あるとき、設定メニューの「Monitors」（モニター）にはモニターごとのチェックボックスがあり、チェックしたすべてのモニターで同時に全画面再生します（←→ でモニターを選び、スペースでチェック）。

- すべてのモニターは同じタイマーで動き、一緒に終わります。どのモニターで Esc を押しても全部止まります。
- 一時停止、パターンの切り替え、チェック画面の段階の切り替えは全モニターで同期します。
- 終了後のシャットダウンやスリープのカウントダウンは 1 回だけです（カウントダウン中、他のモニターは黒になり、どのモニターでキーを押してもキャンセルできます）。スクリーンセーバーは全モニターで再生します。
- チェック画面のマークはモニターごとに別々に保存します。

技術的には、最初にチェックしたモニターをメインのプログラムが表示し、他のモニターにはそれぞれ同じプログラムをもう 1 つ起動します（タスクマネージャーに複数の `go-screen-burn-in-fixer.exe` が見えます）。メインのプログラムが終了すると一緒に終了します。

### シャッフル再生

「Patterns」（パターン）の横で「Shuffle」（シャッフル）を選ぶと、各パターンの時間を短く区切り、他のパターンと交互に再生します。例えば gray-noise を 40 秒、vstripes を 25 秒、moving-bar……と再生し、また gray-noise に戻ります。

- リストの各パターンの秒数は **1 ラウンドの合計時間** になり、シャッフルしても合計は変わりません。
- 「Slice」（1 区切り）は 15–60 秒のランダム（標準）、または 10、20、30、60 秒の固定から選べます。
- 同じパターンが連続することはありません。再生時間が 1 ラウンドより長いときは、ラウンドごとにシャッフルし直します。あるパターンが 1 ラウンドの半分以上を占める場合、他のパターンと交互にできるよう、そのパターンの各区切りが長くなります。
- 情報バーには、このラウンドでそのパターンを再生した時間が表示されます。例：「gray-noise   this round 3:20 / 10:00」（このラウンド 3:20 / 10:00）。

### 再生時間

「Play time」（再生時間）は ◀▶ でよく使う値（10 秒、30 秒、1 分、5 分～24 時間）を選べるほか、その行を選んでいるときは直接入力もでき、最長 72 時間です。単位を付けない場合は分です。

| 入力 | 意味 |
|---|---|
| `90` | 90 分 |
| `10s` | 10 秒 |
| `3m` | 3 分 |
| `3h` | 3 時間 |
| `1m30s` | 1 分 30 秒 |
| `2:30`、`2h30m` | 2 時間 30 分 |

Enter で確定、Esc で入力を取り消します。

### Burn-In 再生中のキー

| キー | 機能 |
|---|---|
| Esc | 設定メニューに戻る（コマンドライン引数で起動したときは終了） |
| スペース | 一時停止 / 再開 |
| ← / → | 前 / 次のパターン |
| H | 情報バーの表示 / 非表示（現在のパターン、残り時間、FPS） |
| S を押し続ける | 押している間だけ情報バーを表示 |

### チェック画面

- チェックする項目にチェックを入れると、順番に実行します。複数の「段階」がある項目（例：near-black は 4 段階）では、秒数は 1 段階あたりの時間です。
- 各項目は秒数（5–120 秒）または「Manual」（手動：Enter／スペースで次の段階へ）に設定できます。上部の「Set all」（すべて設定）で、全項目を自動 10 秒または手動にまとめて設定できます。
- グレー階調の段階数は ◀▶ でよく使う値（8、16、32、64、128、256）に切り替えられ、その行を選んでいるときは数字（2–256）を直接入力できます。
- **gray-field** は最も暗い値・最も明るい値（0–255、標準 13 と 191）と段階数（4–15、標準 7）を設定でき、各欄は選んでいるときに直接入力できます。
  - 最も暗い値から最も明るい値までを n 段階に均等に分けて順に進みます。自動では各段階を設定した秒数だけ表示し、手動では Enter で進みます。段階数は範囲内の階調数を超えません（例：3–4 は 2 段階のみ、最も暗い値と最も明るい値が同じなら 1 段階）。
  - チェック中は**マウスの右ボタンを押したまま左右にドラッグ**するとグレーを調整できます（左で暗く、右で明るく。画面の幅全体が最も暗い値から最も明るい値に対応）。ドラッグするとこの項目は手動に切り替わり、その後 Enter で今より明るい次の段階に進みます。
  - 情報バーにはグレーの値、パーセント、何段階目かを表示します。例：「Gray 128 (50.2%)   item 1/8, step 4/7」（グレー 128（50.2%）、7 段階中 4 段階目）。
- すべて終わるか Esc で取り消すと、チェックのメニューに戻ります。

| キー | 機能 |
|---|---|
| Enter／スペース | 次の段階（手動では必須、自動では早めに進める） |
| ← | 前の段階 |
| 右ドラッグ | gray-field：左右にドラッグしてグレーを調整（手動に切り替わる） |
| Esc | 取り消してチェックのメニューに戻る |
| マウス | 動かすと十字カーソルとピクセル座標を表示。クリックで気になる場所をマーク、もう一度クリックで取り消し |
| C | マークをすべて消去 |
| M | マークの非表示 / 表示 |
| H | 情報バーの表示 / 非表示 |
| S を押し続ける | 押している間だけ情報バーを表示 |

マークは保存され次回も残るので、Burn-In 修復の後に同じ場所をもう一度チェックできます。チェックのメニューで消去できます。

### 情報バー

設定メニューの「Info bar」（情報バー）で、再生中とチェック中に左上に出る情報バーの表示方法を決めます（Burn-In とチェックで共通）。

| 設定 | 動作 |
|---|---|
| Off（表示しない） | 通常は表示しない。S を押し続けるか H を押したときだけ表示 |
| 3／5／10 s | パターンや段階が切り替わったとき、マウスを動かしたときに指定の秒数だけ表示（標準 5 秒） |
| Always（常に表示） | 常に表示 |

### タイマーと終了後の動作

| 動作 | 説明 |
|---|---|
| `quit` | プログラムを終了 |
| `shutdown` | 60 秒のカウントダウン後にシャットダウン（カウントダウン中に何かキーを押すとキャンセル） |
| `sleep` | 60 秒のカウントダウン後にスリープ（カウントダウン中に何かキーを押すとキャンセル） |
| `screensaver` | 点滅を止めてスクリーンセーバーに切り替え、キーを押すかマウスを動かすと終了 |

カウントダウン、警告、メッセージ画面と情報バーの文字は、ゆっくり暗くなったり明るくなったり（呼吸）して、同じ明るさで同じ場所にとどまり続けないようにしています。文字そのものが焼き付きの原因にならないようにするためです。

### コマンドライン引数

再生関連の引数（`-program`、`-timer`、`-after`、`-screensaver`、`-monitor`、`-check`、`-shuffle`）を付けて実行すると、警告画面と設定メニューを飛ばしてすぐに再生を始めるので、タスクスケジューラーなどに便利です。これらの引数はその回の実行だけに使われ、設定ファイルは変わりません。

```
go-screen-burn-in-fixer.exe -program "gray-noise:600,vstripes:300,solid-cycle:120" -timer 30m -after screensaver
go-screen-burn-in-fixer.exe -monitor all -shuffle -timer 1h -after sleep
```

| 引数 | 説明 |
|---|---|
| `-program` | 再生リスト。`パターン:秒数` をカンマ区切りで指定（標準：全パターンを順番に、合計 50 分） |
| `-timer` | タイマーの長さ。例：`30m`、`1h` |
| `-after` | 時間が来た後の動作：`quit`、`shutdown`、`sleep`、`screensaver` |
| `-screensaver` | スクリーンセーバーの名前 |
| `-monitor` | 使うモニター（1 から）：`2`、`1,2`、または `all`（すべて） |
| `-shuffle` | シャッフル再生 |
| `-shuffle-slice` | シャッフル時の 1 区切りの秒数。`0` は 15–60 秒のランダム |
| `-lang` | 画面の言語：`en`（英語、標準）または `zh`（繁体字中国語） |
| `-list` | すべてのパターンとスクリーンセーバーを一覧表示 |
| `-list-monitors` | モニターを一覧表示（現在の解像度と EDID のネイティブ解像度） |
| `-windowed` | ウィンドウモードで実行 |
| `-dry-run` | テスト用：時間が来ても実際にはシャットダウンやスリープをしない |
| `-countdown` | シャットダウン / スリープ前のカウントダウン時間（標準 `60s`） |
| `-check` | すぐにチェックを開始。例：`"gray-field:10,gray-steps:manual,white"`（1 段階の秒数または `manual`。省略時はメニューの設定）。終了するか Esc でプログラムを終了 |
| `-gray-levels` | グレー階調の段階数（2–256） |
| `-gray-min` / `-gray-max` | gray-field の最も暗い値・最も明るい値（0–255） |
| `-gray-field-steps` | gray-field の段階数（4–15） |

## ビルド

Go 1.27 以降が必要です。全プラットフォームの配布ファイル（Windows exe、macOS .app、Linux tar.gz）を `dist/release/` にまとめてビルドします。

```
python tools/release/build.py
```

すべて `CGO_ENABLED=0` で、どのシステムからでもクロスコンパイルできます（Ebitengine は macOS、Linux で cgo が不要）。Windows 版だけをビルドする場合：

```
go build -trimpath -ldflags "-s -w -H windowsgui" -o dist/go-screen-burn-in-fixer.exe .
```

exe のアイコン、バージョン情報、manifest は `winres/` から作られ、[go-winres](https://github.com/tc-hib/go-winres) が `rsrc_windows_*.syso` を生成します（バージョン管理に含まれ、`go build` が自動で使います）。アイコンやバージョンを変えたら作り直してください。

```
go install github.com/tc-hib/go-winres@latest
go run ./tools/icon                      # winres/icon.png、icon16.png を描き直す（バージョンだけ変えるときは不要）
go-winres make --arch amd64,arm64
```

プレビュー動画の生成（ffmpeg が必要）：

```
go run ./cmd/preview
```

## パターンの追加

各パターンは `patterns/` にある `.go` と `.kage`（Ebitengine のシェーダー）のファイルの組で、`init()` で登録するので、他のコードを変える必要はありません。詳しい手順は [CLAUDE.md](CLAUDE.md) の 3.3 節（中国語）を参照してください。スクリーンセーバー（`screensaver/`）とチェック画面（`checks/`）も同じ方法です。
